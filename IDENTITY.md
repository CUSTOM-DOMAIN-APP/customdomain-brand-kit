# CustomDomain™: identity specification

The written source of record behind **https://customdomain.ai/brand**.

Every value below was checked against the live brand page and its published tokens
([tokens.css](https://customdomain.ai/brand/tokens.css), [tokens.json](https://customdomain.ai/brand/tokens.json))
on 2026-09-26. Section 5 was rewritten that day for the CustomDomain™ name; the copy of this file served at
customdomain.ai/brand still gives the retired two-word name until the page is updated.

## 1. The mark

An oak. Two constructions:

**Flat** (lockups, favicon): six-circle canopy, rounded trunk 36×150 rx 18, two-stroke roots. Artboard 512×512.

**Grounded** (app icon, BIMI): same canopy language plus a horizon stroke at y=302 and a three-root flare.

Color: `#1c1917` on paper, `#fafaf9` on ink. Never green.

## 2. The wordmark

Inter SemiBold 600, all caps, +0.18em.

The drawn wordmark files predate the rename. The caps and serif wordmarks, the horizontal and stacked lockups,
and the endorsement line all still set the retired two-word name (`CUSTOM DOMAIN`, or `Custom Domain` in the
serif and endorsement files). They are being redrawn for CustomDomain™.

Display type on the site is Instrument Serif Regular: a headline, not the wordmark.

Instrument Serif · Inter · Geist Mono.

## 5. Name

**CustomDomain™**: one word, capital C and capital D, with the ™, every time the product is meant. Never two
words ("Custom Domain"), never "Customdomain", never "CUSTOM DOMAIN" as a name in prose, and never without the ™.

The generic concept stays lowercase: "connect a custom domain", "custom domains for SaaS". The URL is
customdomain.ai, always lowercase. Never "Connect Domain" in prose. Code identifiers and package names
(`customdomain-js`, `@customdomain/react`) keep their own spelling.
